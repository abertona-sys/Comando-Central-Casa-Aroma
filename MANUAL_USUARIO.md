# 🌸 Manual de Usuario: Comando Central Casa Aroma

Este manual detalla el funcionamiento de la suite empresarial para emprendedoras de wax melts.

## 📌 1. Pestaña: Stock (Insumos)
En esta sección gestionas tu materia prima.
- **Registro:** Añade cera, esencias, envases, etc.
- **Unidades:** Puedes elegir entre gramos, kilos, mililitros o unidades.
- **Control:** Usa los botones de ajuste rápido para cambios menores.

## 📌 2. Pestaña: Recetas (Producción)
Aquí defines "la fórmula" de tus productos terminados.
- **Importante:** Debes crear una receta para cada producto que vendes (ej: "Placa 50g").
- **Relación:** Selecciona los insumos del stock que consume esa placa.
- **Uso:** Esto permite que al vender una placa, se resten automáticamente los gramos de cera y mililitros de esencia correspondientes.

## 📌 3. Pestaña: Marketing (IA)
Asistente para creación de contenido.
- **Objetivo:** Generar guiones cortos y potentes para redes sociales.
- **Personalización:** Indica el producto y el evento o nicho para que la IA adapte el tono.

## 📌 4. Pestaña: Ventas (CRM)
Gestión de clientas y automatización de stock.
- **Registro de Venta:** Cada vez que entregas un pedido, regístralo aquí seleccionando el producto de tu "Recetario".
- **Descuento Automático:** El sistema actualizará tu stock de insumos en tiempo real basándose en la receta del producto vendido.
- **Mensajes de Seguimiento:** Usa la IA para redactar mensajes de WhatsApp personalizados para invitar a clientas antiguas a reponer sus aromas.

## 📌 5. Pestaña: Mentora
Asesoría empresarial instantánea.
- **Consultas:** Pregunta sobre costos, estrategias de venta o dudas técnicas.
- **Tono:** Recibirás respuestas de una experta en negocios artesanales.
